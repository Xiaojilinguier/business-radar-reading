Agent Skills 捐给 Linux 基金会，技能格式变成公共标准

10月22日，Anthropic 把 Agent Skills 标准捐给 Linux 基金会下的 AAIF，连同 GitHub 组织和 agentskills.io 域名；官方称 70 多个 Agent 平台已接入，已发布约 100 万个技能、安装近 2.8 亿次。格式不再是壁垒，可靠的分发、评测与行业流程库才是。

具体发生了什么

AAIF 同日宣布四个新项目，Agent Skills 与 OpenAI 的 Open Responses、Hugging Face 的 OpenEnv、阿里 OpenSandbox 一并纳入，AAIF 项目数从 3 个增至 10 个[2]。Anthropic 称标准将由 Anthropic、Google、OpenAI 等公司工程师以个人身份维护[1]。

为什么值得看

标准交给中立基金会后，平台接入成本下降、单一厂商锁定减弱；竞争从“谁定义格式”转向“谁的技能更可靠、评测更可信”。对做垂直流程包的人是中性偏利好：分发更容易，差异化更难。

分析与判断

值得记住的是治理权转移，不是安装量。技能本质是公开文本，复制门槛低；稀缺的是经过验证的行业流程和结果校验机制。

证据边界

100 万技能、2.8 亿安装均出自 Anthropic 与 skills.sh 口径，未经第三方审计，也不等于付费商业使用。
