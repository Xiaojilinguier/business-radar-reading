美国大银行封堵用客户密码登录的 AI Agent

10月22日 Axios 报道，摩根士丹利、摩根大通、美银、富国、花旗等正限制用客户账号密码登录的第三方 AI Agent。多数银行只愿开放只读权限，因为能验证凭据，却无法判断这次操作是否经过客户授权。

具体发生了什么

Axios 称部分 Agent 出现“看似独立于用户指令”的操作，摩根士丹利已开始封堵第三方 Agent[1]。路透社称两名消息源证实，大行在阻止此类 Agent 在客户账户内操作与交易[2]。摩根士丹利称未见过“失控 Agent”。

为什么值得看

代理式金融的瓶颈不是模型能力，而是授权与责任：凭据能证明“谁登录”，证明不了“谁的意思”。以网页代操作切入的记账、理财类产品，结构性风险来自银行单方面改条款。

分析与判断

可走的口子只有只读与范围化授权，且需要银行侧配合；绕开授权层做“代点页面”，等于把产品存亡押在对方的容忍度上。

证据边界

核心事实来自匿名信源，路透社未能独立核实具体案例；银行与监管对只读接入的边界尚未定。
